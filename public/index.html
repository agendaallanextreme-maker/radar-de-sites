Configurações

As chaves ficam só neste computador, no arquivo de dados.

Usada para buscar no Google Maps e para medir a velocidade dos sites. Como criar: no Google Cloud Console, ative "Places API (New)" e "PageSpeed Insights API" e crie uma chave em Credenciais. O Google pede cartão, mas o uso abaixo da cota gratuita não é cobrado.

A cota gratuita é de 1.000 consultas por mês (cada consulta traz até 20 negócios). Acima disso o Google cobra US$ 35 por mil. O limite padrão de 900 deixa uma margem.

Use {empresa}, {meu_nome}, {problemas} e {site}. Deixe vazio para a mensagem padrão.
